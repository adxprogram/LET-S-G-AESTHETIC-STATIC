# Let's G Aesthetic and Wellness Services

A high-end, responsive web platform for a specialized medical spa and relaxation center based in Valenzuela City. This project serves as a premium virtual storefront featuring a high-contrast Black, White, and Gold aesthetic.

## Features
* **Modern UI/UX:** Minimalist, editorial-style layout with smooth scroll animations.
* **Theme Toggle:** Dynamic Dark and Light mode support using CSS variables and SVG icons.
* **Interactive Menu:** Space-saving service menu utilizing clean, modal-based pop-ups for service details.
* **Responsive Design:** Fully mobile-optimized with a custom hamburger navigation menu.
* **Backend Integration:** PHP/MySQL ready for "Sanctuary Club" loyalty program sign-ups.

## Tech Stack
* **Front-end:** HTML5, CSS3, Vanilla JavaScript
* **Back-end:** PHP (PDO)
* **Database:** MySQL
